# PetCare360 - Easy HTML Pages & Templates

Is folder me project ke sabhi **5 Main Pages** ki bilkul simple, clean aur aasan HTML files banayi gayi hain. 
Aap inme se kisi bhi file par **Double Click** karke bina kisi server ya build ke seedhe apne browser (Chrome / Edge) me open kar sakte hain!

---

## 📁 Files Overview

| File Name | Page Description & Task |
|---|---|
| **`1-dashboard.html`** | **Home & Discovery Interface**: Species categories (Dogs, Cats, Birds), Care resources, Clinic listings, and Service highlights. |
| **`2-clinics.html`** | **Details & Management Interface**: Veterinary clinic directory with specialty/location filters, consultation fees, and available slots. |
| **`3-pets.html`** | **Directory & Filtering Interface**: Pet profiles, care routines (diet, exercise, medications, grooming), vaccination history mockups, and "+ Add Pet" modal. |
| **`4-appointments.html`** | **Workflow & Tracking Interface**: Appointment booking form, confirmed visits with reference codes, interactive care reminders checkboxes, and pet diary. |
| **`5-ai-insights.html`** | **AI — Behavior / Data Insights**: Pet-specific AI routine organizer, wellness score, and 5 visual data displays (Popular services, preferred clinics, appointment patterns, reminders, activity summaries). |
| **`style.css`** | Sabhi pages ke liye clean, reusable aur easy-to-understand CSS styling. |

---

## 💡 Kaise Use Karein:
1. `html-pages` folder me jaiye.
2. `1-dashboard.html` par double click kijiye.
3. Upar navigation bar me kisi bhi page ke link par click karke aap baaki sabhi pages par ghoom sakte hain!
